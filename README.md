# парковка (лаба 3)

rest api для парковки. у пользователей есть машины, машины заезжают в парковочные зоны и выезжают, за стоянку считается сумма.
для постоянных клиентов есть абонементы. данные хранятся в postgresql.

## сущности

- user: пользователь (имя, email)
- vehicle: машина (номер), у каждой есть владелец, у пользователя может быть много машин
- parkingzone: парковочная зона (вместимость, цена за час)
- parkingsession: стоянка машины в зоне (время въезда и выезда, сумма)
- parkingpass: абонемент машины на зону (срок действия, статус active или cancelled)

если удалить пользователя, машину или зону, то все связанные с ними записи тоже удаляются.

## бизнес-операции

- въезд: `POST /api/parking-sessions/entry?vehicleId=1&zoneId=1`. нельзя, если машина уже на парковке или в зоне нет мест.
- выезд: `POST /api/parking-sessions/{id}/exit`. сумму считает сервер, начатый час считается за целый. если у машины есть действующий абонемент на эту зону, стоянка бесплатная.
- оформить абонемент: `POST /api/parking-passes/purchase?vehicleId=1&zoneId=1&days=30`. нельзя, если у машины уже есть действующий абонемент на эту зону.
- продлить абонемент: `POST /api/parking-passes/{id}/extend?days=10`. нельзя, если абонемент отменён или уже закончился.
- передать машину другому пользователю: `POST /api/vehicles/{id}/transfer?newOwnerId=2`. нельзя, пока машина на парковке. абонементы машины при передаче отменяются.

сессии и абонементы создаются и меняются только этими операциями. остальное обычный crud: `/api/users`, `/api/vehicles` (при создании нужен `?ownerId=`), `/api/parking-zones`, `/api/parking-sessions`, `/api/parking-passes`.

## запуск

1. создать файл `.env` по образцу `.env.example`, там пароль пользователя бд.
2. создать базу, таблицы, пользователя бд `parking_app` и тестовые данные: `psql postgres -v app_password="пароль из .env" -f db/init.sql`. этот пользователь может только читать и менять данные, таблицы создавать не может.
3. запустить: `mvn spring-boot:run`.

проверка: импортировать `lab3.postman_collection.json` в postman и запустить всю коллекцию. она создаёт данные, выполняет все операции (и те, что должны вернуть ошибку) и в конце всё удаляет.
